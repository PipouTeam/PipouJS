# Backend Admin - PipouJS

Interface d'administration pour gérer les utilisateurs et les articles.

## Fonctionnalités

- Connexion sécurisée (JWT)
- Dashboard avec statistiques
- Gestion des utilisateurs (activation/désactivation, création staff)
- Gestion des articles (CRUD complet)

## Prérequis

- Node.js installé
- BackendAPI démarré sur le port 3001

## Installation

```bash
cd backend-admin
npm install
npm run dev
```

## Accès

- URL : http://localhost:3002
- Seuls les rôles `admin` et `super_admin` ont accès
